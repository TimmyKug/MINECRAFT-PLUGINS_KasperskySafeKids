# KasperskySafeKids
KasperskySafeKids is a simple but effective plugin that enables Minecraft players to lock their things (chests, shulker boxes, entities), so they cannot be griefed. Mined on Paper 1.21.x using Gradle.

It now also supports regional limits (e.g. spawn only) via `config.yml`. If empty, it works as a global protection everywhere.
