# KasperskySafeKids
KasperskySafeKids is a simple but effective plugin that enables Minecraft players to lock their things (chests, shulker boxes, entities), so they cannot be griefed. Paper 1.21.x.

It now also supports regional limits (e.g. spawn only) via `config.yml`. By default, this is disabled (`use-regions: false`) and works as a global protection everywhere. Set it to `true` to activate the spawn-only (or other custom) restriction.

### Permissions
* `kasperskysafekids.lock` - Allows a user to use the `/lock` command and protect their containers. Default: OP.
